# Archive recovery and language settings

Actual SwiftUI views rendered by `ArchiveDiscoveryTests.testRecoveryAndLanguageSettingsAcrossPhoneDuoAndPad`, running on an iPhone Duo simulator with iOS 27.1. English and Russian sets include phone, outer Duo, inner Duo and iPad layouts. The native in-game modal uses a scrollable list and keeps Continue visible when content exceeds the screen.

| Layout | Points | PNG pixels (2×) |
| --- | --- | --- |
| Phone | 390 × 844 | 780 × 1688 |
| Duo outer | 466 × 678 | 932 × 1356 |
| Duo inner | 669 × 951 | 1338 × 1902 |
| iPad | 1032 × 1376 | 2064 × 2752 |

Files named `archive-{en,ru}-{layout}.png` show three records recovered after restoring the Lighthouse. Files named `language-{en,ru}-{layout}.png` show the saved in-app language choice. These are documentation and layout captures; the phone and Duo renderings do not use App Store screenshot-slot pixel dimensions.
