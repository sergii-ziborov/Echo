# Captioned ECHO screenshots

EN/RU sets for iPhone 6.9-inch, iPhone 6.5-inch, iPad 13-inch and both Duo displays. Editorial captions are native text, with actual ECHO UI underneath; no game interface was invented by an image model. `layouts.json` keeps the composition editable. Generate it with `python3 scripts/prepare_marketing_layouts.py`, then run `swift scripts/render_marketing.swift docs/app-store/marketing-1.1.0/layouts.json` from the repository root.

The Watch slide distinguishes 36 standalone rooms from the separate iPhone remote. The remote slide shows setup (Home plus the Watch waiting screen), not a claim that these stills prove a successful live connection. Native Watch screenshots are in the capture folder. UI fixtures and reused unchanged gameplay sources are listed in `provenance.json`; neither is substituted for physical-device checks.

App Store placement evidence is in `../metadata-1.1.0/SCREEN_UPLOADS.json`. The public listing changes only after App Review and release. Earlier screenshots remain in their historical directories for comparison.
